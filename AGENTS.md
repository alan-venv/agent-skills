# AGENTS.md

Context and instructions for AI coding agents.

## Project Overview

A collection of reusable agent skills.

## General Guidelines

- Use short, specific, kebab-case skill names and keep the directory name and the `name` frontmatter field identical.
- Keep skills short and focused. Place detailed guidance in references and link to it.

## Project Structure

- `skills/`: Skill definitions, one kebab-case directory per skill.
- `scripts/`: Installer for copying a skill into a target project.
