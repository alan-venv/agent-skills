# Glossary

Define the domain vocabulary of the project, so agents understand the terms used in requests and in the code.

## Inspect the Project

1. Read the project documentation, specifications, and user-facing text for business terms.
2. Read domain models, database schemas, and API contracts for terms used in the code.

## Write the File

- Include only terms specific to the project's domain. Omit generic technical terms.
- Define each term by its meaning in this project, based on documentation or clear usage in the code.
- Use one bullet per term.
- Sort terms alphabetically.

## Starting Structure

```md
# Glossary

Domain terms used in the project.

- $TERM: $DEFINITION.
```

## Review

- Every definition is supported by the project or the user.
- No generic technical terms or placeholders remain.
